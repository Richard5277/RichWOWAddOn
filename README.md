# RichWOWAddOn
A simple WoW AddOn for changing the camera distance.

## Commands

- `/far` - moves the camera farther away.
- `/close` - restores a closer camera distance.

## Controller scaling

Hold the LT or RT trigger to scale the main action-bar buttons by 1.35.
Release the trigger to restore their normal size.

## Installation

Copy this entire `RichWOWAddOn` folder into your WoW client's `Interface/AddOns` folder.
